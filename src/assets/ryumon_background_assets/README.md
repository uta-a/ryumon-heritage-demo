# 龍門精舎 背景・装飾アセット集

スクリーンショットを参考に生成した装飾用画像を個別ファイルに整理しています。人物・建物は含みません。

- `backgrounds/`: 背景13点（1920×1080）。画像生成の一覧シートから切り出し、拡大したもので、ネイティブ解像度のディテールはありません。
- `overlays/`: 透過PNG装飾3点。背景の白を推定処理で除去したものです。
- `asset_manifest.csv`: 素材の内容と推奨用途。

この装飾は実際の霊符・文化財の複製ではなく、一般的な装飾モチーフとしての新規生成素材です。宗教上の意味を持つ図像としての利用は避けてください。
