# 龍門精舎 画像生成プロンプト

12個の画像枠に対応するプロンプト集。`gpt-image-2` で全12点を生成し、Webサイトへ挿入済み。表示用WebPは合計約2MB。

## 使い方

1. 対応するファイルの「生成プロンプト」から「使用前の確認」の手前までを生成ツールに入力する。禁止事項も省略しない。
2. 各ファイルの構図とサイズを参考に設定する。サイズは仕上がりの目安であり、APIが受け付ける値を保証するものではない。
3. 出力を目視で確認し、人物、建物、文字、宗教図像が混入した画像は採用しない。
4. サイトに配置する際はWebPに変換し、画像パスと代替テキストを変更する。代替テキスト案は各ファイルに記載している。
5. AI生成のイメージ画であることをページ上に表示する。実写真に見せかけない。

## DESIGN.mdに基づく制約

`DESIGN.md` の2.3、2.4、10.2を優先する。AI生成の架空人物、偽の店舗写真、架空の儀式写真は禁止。霊符や宗教図像の捏造も行わない。

人物、儀式、商品は非写実の素材イメージ画として指定している。寺院画像のみ、ユーザーの選択に基づき仏国寺・極楽殿のCC0写真を添付参照した建築イラストに変更した。寺院名と龍門精舎の実店舗ではないことを画像の近くに明示し、アクセス欄には使用しない。参照写真の出典と利用条件は `temple.md` と素材台帳に記録している。実在の先生、店舗、商品を正式に紹介する画像には許諾のある実写真を用意する。

装飾背景は提供済み素材を使用しているため、このフォルダには背景の再生成用プロンプトを含めていない。画像生成原本は `src/assets/generated-images/`、表示用画像は `public/images/` に保存。モデル、対応プロンプト、実際の寸法は `src/assets/generated-images/manifest.json` を参照する。生成画像は目視確認済みで、ページ上にもAI生成イメージであることを明示している。
